Moduł 01

Intuicja Geometryczna: Jak porusza się cena akcji?

Monte Carlo Engine

Zanim sformułujemy abstrakcyjne równania różniczkowe, musimy zrozumieć, skąd bierze się niepewność. Ceny akcji podlegają Geometrycznemu Ruchowi Browna (GBM). Zakładamy, że względne stopy zwrotu składają się ze stałego trendu (dryfu $\mu$) oraz losowych zaburzeń białego szumu skalowanych zmiennością ($\sigma$):

Stochastyczne Równanie Różniczkowe (SDE):
$$dS_t = \mu S_t dt + \sigma S_t dW_t$$

Gdzie $W_t$ to proces Wienera (standardowy ruch Browna, $W_t \sim \mathcal{N}(0, t)$). Ponieważ cena akcji nie może spaść poniżej zera ($S_t > 0$), logarytm ceny $\ln(S_t)$ ma rozkład normalny, co oznacza, że sama cena $S_T$ ma rozkład log-normalny z asymetrycznym prawym ogonem.

👉
Jak z tego korzystać: Zmieniaj suwaki zmienności $\sigma$ oraz czasu $T$. Zauważ, jak przy wyższej zmienności wachlarz trajektorii rozszerza się, a dzwon rozkładu po prawej stronie spłaszcza się. Linia przerywana to cena wykonania $K$ (Strike). Zielone ścieżki kończą w cenie (ITM, zysk z opcji Call), a czerwone poza ceną (OTM).

Moduł 02

Rygor Formalny: Od Lematu Itô do Równania PDE

Dowód Analityczny

Geniusz Fischera Blacka, Myrona Scholesa i Roberta Mertona polegał na uświadomieniu sobie, że opcji nie wycenia się przez szacowanie przyszłego wzrostu spółki ($\mu$), lecz przez zbudowanie dynamicznie zrównoważonego portfela syntetycznego, w którym ryzyko rynkowe ulega całkowitej anihilacji.

1

Rozwinięcie ceny opcji $V(S, t)$ z Lematu Itô

Niech $V(S, t)$ oznacza cenę opcji. Na mocy stochastycznego Lematu Itô dla funkcji dwóch zmiennych:

$$dV = \left(\frac{\partial V}{\partial t} + \mu S \frac{\partial V}{\partial S} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2}\right)dt + \sigma S \frac{\partial V}{\partial S} dW_t$$
2

Konstrukcja Portfela Delta Hedging ($\Pi$)

Konstruujemy portfel składający się z jednej długiej opcji $V$ oraz krótkiej pozycji w $\Delta$ jednostkach akcji: $\Pi = V - \Delta S$. W nieskończenie małym przedziale czasu $dt$:

$$d\Pi = dV - \Delta dS = \left(\frac{\partial V}{\partial t} + \mu S \frac{\partial V}{\partial S} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} - \Delta \mu S\right)dt + \left(\sigma S \frac{\partial V}{\partial S} - \Delta \sigma S\right)dW_t$$

Jeżeli wybierzemy $\Delta = \frac{\partial V}{\partial S}$ (współczynnik Delta), człon losowy $dW_t$ znika do zera! Portfel staje się całkowicie deterministyczny i bezryzykowny.

3

Zasada Braku Arbitrażu i Równanie Różniczkowe Cząstkowe (PDE)

Aby zapobiec darmowemu arbitrażowi na rynku, każdy portfel wolny od ryzyka musi generować stopę wolną od ryzyka $r$: $d\Pi = r \Pi dt$. Podstawiając $\Pi = V - \frac{\partial V}{\partial S} S$, otrzymujemy słynne równanie PDE Blacka-Scholesa:

$$\frac{\partial V}{\partial t} + rS \frac{\partial V}{\partial S} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} - rV = 0$$
Kluczowa konkluzja naukowa: Zwróć uwagę, że parametr oczekiwanego wzrostu akcji $\mu$ zniknął bez śladu. Cena godziwa opcji nie zależy od tego, czy inwestorzy są optymistami czy pesymistami co do spółki. Zależy wyłącznie od bieżącej ceny $S$, strike'a $K$, czasu $T$, stopy wolnej od ryzyka $r$ oraz zmienności $\sigma$.
4

Zamknięte Wzory Analityczne (Closed-Form Formulas)

Rozwiązując powyższe równanie PDE z warunkami brzegowymi wypłaty przy wygaśnięciu $V(S, T) = \max(S-K, 0)$ dla Call oraz $\max(K-S, 0)$ dla Put, uzyskujemy:

Opcja Europejska Call ($C$):
$$C(S, t) = S e^{-qT} N(d_1) - K e^{-rT} N(d_2)$$
Opcja Europejska Put ($P$):
$$P(S, t) = K e^{-rT} N(-d_2) - S e^{-qT} N(-d_1)$$
$$d_1 = \frac{\ln(S/K) + (r - q + \frac{1}{2}\sigma^2)T}{\sigma\sqrt{T}}$$
$$d_2 = d_1 - \sigma\sqrt{T} = \frac{\ln(S/K) + (r - q - \frac{1}{2}\sigma^2)T}{\sigma\sqrt{T}}$$
Parytet Kupna-Sprzedaży (Put-Call Parity): $$C - P = S e^{-qT} - K e^{-rT}$$

Moduł 05

Odwracanie Modelu: Zmienność Implikowana i Volatility Smile

Algorytm Newtona-Raphsona

W rzeczywistości rynkowej nie znamy zmienności $\sigma$. Widzimy natomiast cenę rynkową opcji $C_{\text{mkt}}$. Zmienność implikowana to wartość $\sigma$, która podstawiona do wzoru Blacka-Scholesa daje dokładnie cenę rynkową. Ponieważ wzoru nie da się odwrócić analitycznie, stosuje się numeryczną metodę Newtona-Raphsona, gdzie pochodną po zmienności jest dokładnie Vega:

$$\sigma_{n+1} = \sigma_n - \frac{C_{\text{BS}}(\sigma_n) - C_{\text{mkt}}}{\text{Vega}(\sigma_n)}$$

Moduł 08

Praktyczna Implementacja w Pythonie (NumPy / SciPy)

Poniższy skrypt przedstawia kompletny, produkcyjny moduł wyceny opcji, analitycznych Greków oraz solwera zmienności implikowanej gotowy do wklejenia w systemie quant tradingowym. 

import numpy as np
from scipy.stats import norm

class BlackScholesEngine:
    """
    Wycena opcji europejskich i obliczanie Greków w standardzie Blacka-Scholesa-Mertona (1973).
    Obsługuje również ciągłą stopę dywidendy q (Merton 1973).
    """
    def __init__(self, S: float, K: float, T: float, r: float, sigma: float, q: float = 0.0):
        self.S = float(S)
        self.K = float(K)
        self.T = float(T)
        self.r = float(r)
        self.sigma = float(sigma)
        self.q = float(q)

    def _d1_d2(self):
        sqrt_T = np.sqrt(self.T)
        d1 = (np.log(self.S / self.K) + (self.r - self.q + 0.5 * self.sigma ** 2) * self.T) / (self.sigma * sqrt_T)
        d2 = d1 - self.sigma * sqrt_T
        return d1, d2

    def price(self, option_type: str = "call") -> float:
        d1, d2 = self._d1_d2()
        disc_r = np.exp(-self.r * self.T)
        disc_q = np.exp(-self.q * self.T)
        
        if option_type.lower() == "call":
            return self.S * disc_q * norm.cdf(d1) - self.K * disc_r * norm.cdf(d2)
        elif option_type.lower() == "put":
            return self.K * disc_r * norm.cdf(-d2) - self.S * disc_q * norm.cdf(-d1)
        raise ValueError("option_type must be 'call' or 'put'")

    def greeks(self) -> dict:
        d1, d2 = self._d1_d2()
        sqrt_T = np.sqrt(self.T)
        disc_r = np.exp(-self.r * self.T)
        disc_q = np.exp(-self.q * self.T)
        pdf_d1 = norm.pdf(d1)

        delta_call = disc_q * norm.cdf(d1)
        delta_put = disc_q * (norm.cdf(d1) - 1.0)
        gamma = (disc_q * pdf_d1) / (self.S * self.sigma * sqrt_T)
        vega = self.S * disc_q * sqrt_T * pdf_d1 * 0.01  # za 1 p.p. sigma

        theta_term = -(self.S * disc_q * pdf_d1 * self.sigma) / (2 * sqrt_T)
        theta_call = (theta_term - self.r * self.K * disc_r * norm.cdf(d2) + self.q * self.S * disc_q * norm.cdf(d1)) / 365.0
        theta_put = (theta_term + self.r * self.K * disc_r * norm.cdf(-d2) - self.q * self.S * disc_q * norm.cdf(-d1)) / 365.0

        rho_call = (self.K * self.T * disc_r * norm.cdf(d2)) * 0.01
        rho_put = (-self.K * self.T * disc_r * norm.cdf(-d2)) * 0.01

        return {
            "delta_call": delta_call, "delta_put": delta_put,
            "gamma": gamma, "vega": vega,
            "theta_call_daily": theta_call, "theta_put_daily": theta_put,
            "rho_call": rho_call, "rho_put": rho_put
        }

    @staticmethod
    def implied_volatility(target_price: float, S: float, K: float, T: float, r: float, 
                           option_type: str = "call", q: float = 0.0, tol: float = 1e-6, max_iter: int = 100) -> float:
        sigma = 0.25  # punkt początkowy
        for _ in range(max_iter):
            bs = BlackScholesEngine(S, K, T, r, sigma, q)
            price = bs.price(option_type)
            diff = price - target_price
            if abs(diff) < tol:
                return sigma
            vega = bs.greeks()["vega"] * 100.0  # raw vega
            if vega < 1e-8:
                break
            sigma -= diff / vega
            sigma = max(1e-4, min(sigma, 5.0))
        return sigma

# Przykład użycia:
if __name__ == "__main__":
    bs = BlackScholesEngine(S=100.0, K=100.0, T=1.0, r=0.05, sigma=0.20)
    print(f"Cena Call: {bs.price('call'):.4f} USD")
    print(f"Cena Put:  {bs.price('put'):.4f} USD")
    print("Grecy:", bs.greeks())
    iv = BlackScholesEngine.implied_volatility(target_price=10.4506, S=100, K=100, T=1.0, r=0.05)
    print(f"Odzyskana Zmienność Implikowana: {iv*100:.2f}%")
